# SCD30 IoT Cloud

This project reads carbon dioxide (CO₂), temperature, and relative humidity from an SCD30 sensor and publishes the CO₂ value to Arduino IoT Cloud.

It is intended for simple environmental monitoring setups where sensor data should be visible from the cloud dashboard or used in other Arduino IoT Cloud integrations.

## Features

- Reads CO₂, temperature, and humidity from an Adafruit SCD30 sensor
- Connects to Arduino IoT Cloud using the Arduino Cloud connection APIs
- Publishes the CO₂ reading as a cloud variable named `co2Value`
- Prints sensor data and uptime to the serial monitor for local debugging
- Samples data on a 10-second interval

## Hardware

- SCD30 CO₂ sensor module
- Compatible Arduino board with Wi-Fi or cellular support for Arduino IoT Cloud
- I²C wiring for the sensor

Typical SCD30 wiring:

- VIN -> 3.3V or 5V depending on your module and board compatibility
- GND -> GND
- SDA -> Arduino SDA pin
- SCL -> Arduino SCL pin

Check your board's I²C pin mapping before wiring, as some boards use different SDA/SCL pins.

## Software requirements

- Arduino IDE
- Adafruit SCD30 library
- Arduino IoT Cloud support libraries and a configured Arduino Cloud Thing

## Project structure

- `SCD30_IoT_Cloud.ino` — main sketch
- `thingProperties.h` — generated by Arduino IoT Cloud and included by the sketch

## How it works

The sketch:

1. Initializes the serial connection.
2. Calls `initProperties()` to prepare the IoT Cloud variables.
3. Starts the Arduino IoT Cloud connection with `ArduinoCloud.begin(...)`.
4. Initializes the SCD30 sensor with `scd30.begin()`.
5. Repeatedly checks whether new sensor data is ready.
6. Reads the sensor values and updates the cloud variable `co2Value`.
7. Prints the current values and uptime to the serial console.

## Cloud variable configuration

The code expects this cloud variable to exist in the Arduino IoT Cloud Thing:

- `float co2Value` (read-only from the dashboard)

If you want to expose more values in the cloud later, you can add them in the Arduino IoT Cloud editor and map them in the generated `thingProperties.h` file.

## Setup steps

1. Install the Arduino IDE and the required libraries.
2. Open the project in Arduino IDE.
3. Create or open an Arduino IoT Cloud Thing and add a `float` variable named `co2Value`.
4. Allow Arduino IoT Cloud to generate the `thingProperties.h` file.
5. Place the generated file in the same project folder as the sketch or ensure it is available to the build.
6. Connect the SCD30 sensor to the board using I²C.
7. Select the correct board and port.
8. Upload the sketch.
9. Open the Serial Monitor to view sensor output and confirm the sensor is detected.

## Notes

- The sensor is read every 10 seconds in this sketch.
- The SCD30 requires a short warm-up period before valid readings become stable.
- If the sensor is not found, the sketch enters a blocking loop and stops execution.
